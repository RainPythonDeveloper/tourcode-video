Glossary

handleLogin
The entry point of login: it takes an email and password and returns either a failure reason or a new session.
passwordHash
The stored, hashed form of a user's password. The login never compares plain passwords, only hashes.
verifyPassword
Hashes the submitted password and checks whether it equals the stored hash.
startSession
Creates a session object with the user id, a start timestamp and a random token after a successful login.
findUser
Looks up a user by email. Here it searches a hard-coded in-memory array.
