Step 3 of 4password.ts:1–7

Verifying the password

verifyPasswordHashes the submitted password and checks whether it equals the stored hash. hashes the submitted password and compares it to the stored hash. It never compares plain text, and returns true only when the hashes match.

  • High · Securityline 6

    hashPassword just reverses the string, so the stored hash is trivially reversible to the original password. Not safe for real credentials.

  • Low · Riskline 2

    The === comparison is not constant-time, which can leak timing information in a real auth system.
