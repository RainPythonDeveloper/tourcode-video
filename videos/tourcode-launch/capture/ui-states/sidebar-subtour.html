Glossary

passwordHash
Field on the user record from findUser; passed to verifyPassword, never compared as plain text.
hashPassword
Private helper in password.ts that transforms the submitted password before comparison.
short-circuit
JavaScript || skips the right side when the left is true; here it skips verifyPassword when user is undefined.
userId
The user.id string from findUser; the only argument startSession receives from handleLogin.
